The connection

Built around your Firefly III instance.

Glowtail is an independent Android client for Firefly III. It connects directly to the Firefly III instance you choose, using its existing authentication with a Personal Access Token. No separate Glowtail account is required. An encrypted HTTPS connection is recommended.

01 / CONNECT

Your server

Use the Firefly III instance you already run or have access to.

02 / AUTHORIZE

Your token

Sign in with a Personal Access Token from that instance.

03 / MANAGE

Your workflow

Work with Firefly III data from an interface designed for your phone.
